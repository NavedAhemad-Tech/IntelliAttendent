IntelliAttendent – Employee Attendance Management System

Project Overview

IntelliAttendent is a Python-based Employee Attendance Management System developed using Streamlit and MySQL. The application helps organizations manage employee records, track daily attendance, monitor attendance history, and generate reports through an interactive dashboard.
